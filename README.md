# Predicción de Diabetes con Machine Learning

Aplicación desarrollada con Python y Streamlit para predecir si un paciente podría presentar diabetes utilizando un modelo de Machine Learning.

## Tecnologías utilizadas

- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git
```

2. Entrar al proyecto:

```bash
cd TU-REPOSITORIO
```

3. Crear entorno virtual:

```bash
python -m venv .venv
```

4. Activar entorno virtual:

### Windows

```bash
.venv\Scripts\activate
```

### Mac/Linux

```bash
source .venv/Scripts/activate
```

5. Instalar dependencias:

```bash
pip install -r requirements.txt
```

## Ejecutar aplicación

```bash
streamlit run app.py
```

## Métricas del modelo

- Accuracy: 0.75
- Recall: 0.67
- F1 Score: 0.65

## Dataset

El proyecto utiliza el dataset `diabetes.csv`.
